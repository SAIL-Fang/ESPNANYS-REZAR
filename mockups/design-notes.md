# SAIL 均衡器概念稿 · 设计说明

## 方向

不是“游戏外设面板”，而是一个安静的桌面音频工具：像 macOS 的系统设置、Logic 的检查器，材质轻，信息密度克制。

- 主视觉：均衡器曲线 + 可编辑数值，而不是一堆卡片。
- 只保留一个强调色：系统蓝 `#2F6BFF`；状态用绿色，不用电竞橙。
- 浅色玻璃作为主材质，背景是冷银灰，不做大面积纯白。

## 命名

- 页面：`声音`
- 区块：`均衡器`
- 频段：`31 Hz`、`63 Hz`……`16 kHz`
- 不再使用“10 段 EQ”这种偏工程/驱动的叫法。
- 说明文案里可以说“10 个频段”，但标题只叫“均衡器”。

## Tokens

| 用途 | 值 |
|---|---|
| 画布 | `#E6EBF0` → `#F5F7F9` 冷银渐变 |
| 主文字 | `#15181E` |
| 次文字 | `#5D6673` |
| 弱文字 | `#8B95A2` |
| 玻璃面 | `rgba(255,255,255,.58)` |
| 强调 | `#2F6BFF` |
| 成功/充电 | `#16845F` |

字体：SF Pro Display / Segoe UI Variable / PingFang SC；数值用 SF Mono / Cascadia Mono。

## 交互

1. 每个频段上方有 `− [数值] +`，数值可直接键入。
2. 支持 `↑` / `↓` 微调，`Enter` 写入。
3. 拖动曲线/滑杆仍然保留；数值输入是精确路径。
4. 激活频段有蓝色描边，曲线上的点与滑杆联动。
5. 预设是一组分段控件，不占四张卡片。

## 需要确认

- 浅色玻璃 vs 深色玻璃（当前是浅色）。
- 数值放在每个频段上方，还是集中成一张“精确输入”表。
- 是否保留 10 根滑杆；如果更偏“精确”，可以只保留曲线 + 数值表。
