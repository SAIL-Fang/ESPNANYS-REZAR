# DeepSeek-chan icon

The supplied DeepSeek-chan image is used as the application icon at the project
owner's direction.

- Source: `deepseek-chan-source.png`
- Master: `deepseek-chan-1024.png`
- The square master is a centre crop of the supplied image with rounded corners.
- The Tauri icon set and `ui/static/favicon.png` are generated from that master.
