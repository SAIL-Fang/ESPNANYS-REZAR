# SAIL whale-chan icon

Original artwork for ESPNANYS-REZAR. It is not copied from DeepSeek fan art
and is not an official DeepSeek mascot.

- Master: `whale-chan-1024.png`
- Generator: `tools/make_whale_icon.py`
- Palette: ocean navy, blue hair, cyan whale cues, white sailor collar
- Cues: whale-fin ears, whale-tail hairpin, water droplets
- The generator also produces the Tauri icon set in `ui/src-tauri/icons/`.

The artwork is released under the project's MIT license.
